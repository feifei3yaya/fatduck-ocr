    云端文本纠错

    可选功能 · 默认关闭

    开启后，对识别存疑的单元格，程序会将该单元格的局部裁剪图与当前识别文字 发送到 NVIDIA 托管模型接口（integrate.api.nvidia.com）做二次确认，用于校正商品名称等 中文文本。该功能面向有自己 NVIDIA API Key 的高级用户，普通用户保持关闭即可。

    · 运单号、日期、数量等编码字段不会外发；
    · 不发送整张图片，只发存疑单元格；
    · 关闭时程序不会向云端发送任何图片或文字；
    · 密钥仅从本机环境变量 IMG2DOC_NVIDIA_KEY 或配置中读取，不写入任何分发文件。
