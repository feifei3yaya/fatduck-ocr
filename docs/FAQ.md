# 常见问题

## 下载与安装

### 应该下载安装包还是便携包？

- **安装包**：双击安装，自动创建开始菜单和桌面快捷方式，适合日常使用。卸载可在「设置 → 应用」里完成。
- **便携包**：解压到任意目录，双击 `肥鸭文档转换.exe` 运行，不写注册表，适合放 U 盘或临时使用。

两个版本功能完全一样。

### 打开时出现蓝色 SmartScreen 警告怎么办？

点「更多信息 → 仍要运行」。这是因为项目没有购买代码签名证书，不是病毒提示。也可以先运行随包附带的「解除锁定.bat」，再启动程序。

### 杀毒软件报毒怎么办？

部分杀毒软件会对未签名的 Python 打包程序误报。可以：

1. 确认安装包来自本项目的 GitHub Releases 页面；
2. 将程序目录加入杀软白名单；
3. 如仍有疑虑，可按 README 从源码运行。

### 支持 Windows 7 吗？

不支持。需要 Windows 10 / 11 64 位，且系统需安装 WebView2 运行时（Windows 11 自带，Windows 10 多数已随 Edge 安装）。

### 支持 Mac / Linux 吗？

macOS 在规划中，Linux 暂不支持。

### 安装会修改什么？

安装包默认装到 `C:\Program Files\肥鸭文档转换`，安装时需要管理员权限，并创建开始菜单快捷方式，可选桌面快捷方式。配置写入 `%APPDATA%\肥鸭文档转换`，任务历史写入 `%LOCALAPPDATA%\肥鸭文档转换\jobs`。卸载时可选择是否删除配置与日志。

## 使用

### 一次可以处理多少文件？

没有硬性页数限制，但一次拖入过多会明显变慢。建议单次不超过 50 页；一次最多 200 个文件，单文件上限 100 MB，请求总量上限 2 GB。

### 支持哪些格式？

PNG、JPG、JPEG、BMP、TIF、TIFF、WEBP、PDF。多页 TIFF 和 PDF 会逐页处理。

### 怎么粘贴截图？

复制图片后，把鼠标移入窗口，会出现「剪贴板里有图片，点击粘贴」的提示，点一下即可。也可以在窗口内按 Ctrl+V。

### 识别需要联网吗？

不需要。OCR 模型和运行时都在本机。

### 为什么识别结果有错字？

OCR 对印刷体效果最好。以下情况容易出错：

- 拍摄模糊、抖动、对焦不准；
- 光线不均、反光、阴影；
- 表格倾斜角度大；
- 字太小或分辨率过低；
- 手写体、艺术字、复杂背景。

建议正对表格拍摄，让表格占满画面，光线均匀。识别没把握的单元格会进入「待复核」，可以逐条核对。

### 「待复核」是什么？

程序把置信度较低的单元格集中列出，支持放大看原图、对照复识结果，并标记「已核对」或「需重拍」。不处理也不影响导出，只是提醒你重点检查。

### 导出的 Excel 格式是怎样的？

默认「一图一表」：每张图片 / PDF 每一页写成一个工作表。也可以选「多图一表」合并到同一个工作表。

### 能识别合并单元格吗？

会尽量按表格网格还原合并关系，但复杂表头、嵌套表格可能需要手工调整。

### 任务历史保存在哪里？

`%LOCALAPPDATA%\肥鸭文档转换\jobs`。默认保留最近 10 个任务，可在设置中调整为 1–50。删除该目录即可清空历史。

## 隐私

### 会上传我的图片吗？

不会。识别全部在本机完成。唯一例外是你主动开启「云端文本纠错」后，程序会把存疑单元格的局部裁剪图和识别文字发送到 NVIDIA 接口做二次确认，不发送整张图片，不发送运单号等编码字段。该功能面向有自己 NVIDIA API Key 的高级用户，普通用户保持关闭即可。

### 「版本检查」会发送什么？

只发送程序版本号和固定 User-Agent 到 GitHub 公开的 Releases 接口，不发送图片、文件名、识别结果或个人信息。可在设置中关闭。

### 日志里会有单号吗？

日志会对运单号等编码类信息做中段打码（保留前 4 后 2）。日志在 `%LOCALAPPDATA%\肥鸭文档转换\logs`。

可以。MIT 许可证允许商用、修改和再分发，保留版权声明即可。

可以，欢迎。构建方式见 README，贡献流程见 CONTRIBUTING.md。

### 发现 Bug 或有功能建议怎么反馈？

到 GitHub Issues 提交，附上系统版本、程序版本、复现步骤。涉及图片时请先打码或使用测试样图，不要上传真实单号和个人信息。
